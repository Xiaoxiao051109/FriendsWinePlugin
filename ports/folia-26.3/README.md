# FriendsWinePlugin 1.1.0（Paper / Folia）

独立服务端插件，原版客户端配合服务器资源包使用，**不需要安装原 Fabric 模组，也不兼容其他玩偶模组**。

当前正式版保留通透模式及原版纹理、首帧优化，并提供玩偶、朋友的酒遥控器、范围蹦迪、和平区域、成年傻子村民交易和原曲循环音乐。**不加入酒饮品、玩家酒劲／镜头动画、角色、生成蛋、NPC 生成／跟随／偷取。玩家不变形、不被牵引。**

## 保留的1.0.0修复与改名

- 修复右击暂停玩偶时停在压缩／自转形状的问题：停止态继续使用原来的姿态采样器写回模型默认姿态，不直接移除动画后留下最后一帧；恢复播放不重建模型。
- 插件名称、入口类和构建名称统一为 FriendsWinePlugin，版本 1.0.0。旧存档PDC命名空间保留，因此已有玩偶ID、遥控绑定、物品和村民补货日继续有效。
- 保留0.2.2的绕圈／越障修复和音乐volume 1.5。物品ID、CE分类、`/tongtou`命令及权限不变。

## 多版本兼容范围与验收状态

| Minecraft | BetterModel | Java最低要求 |
| --- | --- | --- |
| 1.21／1.21.1／1.21.2／1.21.3 | 1.15.2 | 21 |
| 1.21.4～1.21.11 | 1.15.2，或3.5.x | 1.15.2用21；3.5.x用25 |
| 26.1.x～26.3 | 3.5.x（以3.5.0编译） | 25 |

这些是**代码适配与前置选择范围，不是每个组合均已实服验收**。当前已通过最低Paper1.21.1 API编译、全部自有类Java21字节码检查、现有BM3离线回归和资源静态验证。按用户选择，本轮不执行新下载的BM1后端；其运行测试组默认禁用，仅编译。也没有真实Java21运行环境或全版本Paper/Folia联机验收。旧后端启动时会明确提示该边界，不能将`folia-supported`或`api-version`当作验收证明。

资源始终统一来自**26.3官方客户端**，没有分别提取其他Minecraft版本。启动时依据服务器的实体注册表过滤目录和实际安装模型；低版本不存在的实体不交给BetterModel加载。旧版没有的猪／牛／鸡气候属性归一到26.3的temperate基础外观，保留已有变种、装备和姿态的精确保护。

- 1.21～1.21.3：世界模型将不合法的旧格式Cube旋转移到骨骼，保留源几何、PNG和逐面UV；可能增加展示骨骼与包量，实际负载待运行验收。
- **旧版手持按用户选择重制兼容3D**：背包、手持和掉落物仍是51个纹理Cube构成的3D物品，但几何细节允许与原模型不同；放置模型不使用这一简化物品表示。
- 1.21.4起的物品使用复合定义与各子模型的标准display变换，不依赖较新版本的额外矩阵字段；26.x保留原有物品资源路径。
- 早期1.21没有consumable组件时采用兼容的长时间使用组件，绑定、切档、防连发和不消耗语义保留，实际按键表现待验收。
- BM1家具配置不触发CE的BM3专用blueprint绑定，由本插件后端管理同一家具载体上的模型；没有新NPC或第二套可见家具。
- 不支持任意历史／未来BetterModel混装。未来26.x无对应后端／能力时明确报错，不提前宣称兼容。

## 本次实体匹配修复

原问题是配方遗漏，而非模型文件校验失败。补齐：

- 史莱姆、岩浆怪：实际size=1／2／4对应独立尺度，保留史莱姆透明外壳和岩浆怪独有模型／贴图。NBT的Size减一存储不能当成Bukkit getSize。
- 溺尸：成人／幼年独有几何、皮肤及独立外层。额外识别游泳标志，不能用`pose=standing`推断不在游泳。
- 洞穴蜘蛛、流浪商人及河豚0／1／2膨胀状态：各用真实26.3层与贴图，不复用错误物种外形。

原有809个模型内容保留；当前为822个原版条目、79类实体，另加1个玩偶模型。未提供的特殊尺寸、装备、特殊命名、游泳等姿态仍明确拒绝，不就近选错模型。**持三叉戟／钓鱼竿／副手物品或穿甲的溺尸，不属于已提供的空装备基础模型范围。**

## 环境与安装

- 目标为已发布的 Paper／Folia 1.21.x、26.1.x、26.2.x、26.3；Java与模型前置见下方矩阵。不是Spigot通用插件。
- **必需前置：CraftEngine 26.9.2，以及与服务器匹配的 BetterModel Paper版。** 前置不会自动下载或打入插件JAR。
- 插件成品：`build/libs/FriendsWinePlugin-1.1.0-Paper-Folia.jar`。

1. 停服，移除旧版 TongtouMode／tongtou-mode JAR，放入 FriendsWinePlugin-1.1.0-Paper-Folia.jar，不同时保留新旧两个插件。
2. 保留旧 `plugins/TongtouMode/` 目录。首次启动会把已知配置、资源管理账本和播放时钟复制到 `plugins/FriendsWinePlugin/`，不删除旧目录，不覆盖新目录中的既有文件。无需删除 BetterModel 模型目录，无需另装资源 ZIP。
3. 正常启动。插件在 onLoad 释放资源，BetterModel 加载模型；随后自动将生成包合入 CE，并执行 CE 的现有资源包工作流。
4. 玩家接受新资源包。通过 CE 物品菜单的独立「通透模式」分类、管理命令或成年傻子村民获取物品。

“单 JAR”包括：822 个原版外观模型、1 个玩偶模型及嵌入 PNG、手持模型／贴图、56 段页边界偏移音乐、声音定义、CE 三物品／家具／分类配置、目录和完整性清单。**不包括前置插件本体或 Minecraft 客户端／服务端代码**，不会自动下载前置。

沿用 CE 既有托管和下发设置，不覆盖其 config.yml，不开新 HTTP 服务。公网可达性、防火墙及玩家拒绝资源包不由本插件绕过；可用 `resources.ce-workflow` 选择已有工作流。

## 三件物品

| ID | 使用方式 |
| --- | --- |
| `tongtou:mode` | 主手持有，潜行右击非玩家实体，播放一次约 0.91667 秒的回弹、变宽、自转 |
| `tongtou:doll` | 放在地面，四向放置；新放置默认停止。普通右击切换停止／回弹＋自转，破坏回收 |
| `tongtou:remote` | 主手右击玩偶绑定；对空气右击切档，按住不会连续切档 |

遥控顺序：**停止 → 回弹 → 回弹＋自转 → 回弹＋自转＋绕圈 → 停止**。切档不重置正在播放的音乐和回弹相位；从回弹进入自转时单独开始旋转计时。绕圈模式使实体沿玩偶外围持续移动；遇到低矮方块／台阶时尝试原生跳跃和寻路绕行，不传送、不穿墙。

遥控限同一维度，距离不限，只能操作已加载玩偶；不加载区块。绑定记录包含世界、位置和稳定实例 ID，目标区域再次复核实体与状态。移除旧玩偶后在原位置放置新玩偶不会继承遥控绑定。

## 范围玩法

- 播放中的玩偶吸引 **50 格内 Mob**；10 格内叠加回弹显示及近距离平滑牵引；在玩偶周围约 5 格区域分散站位。
- 多玩偶重叠时按三维距离选择最近来源，同距离稳定决胜。切换来源更新同一个持续动画的快照，不反复拆建模型。
- 六角站位会考虑实体尺寸、间距、地形碰撞、危险方块、区块加载与线程归属。没有安全槽位的水生／飞行生物不强拉向无效落点。
- 绕圈默认约 20 秒一圈，受阻时尝试跳跃／绕行，找不到安全可达路径才暂停；可用 `party.orbit-speed` 调整倍率。
- 不传送生物，不改变真实尺寸、碰撞、隐身状态或 AI 总开关。范围内确实会接管寻路／速度，和平规则会清理攻击目标；退出后停止本插件的控制，不恢复过期攻击目标。
- 范围显示优先于手动通透。已有其他插件模型时只叠加、撤销本插件动画；只移除本插件自己创建且身份仍相符的临时 tracker。

### 和平区域

活动玩偶 50 格内，**攻击者或受击者任一在范围内**，抑制 Mob 发起的战斗，包括识别弹射物／药水等真正伤害来源。玩家可以受到保护，但不阻止玩家主动攻击、环境伤害或苦力怕爆炸；苦力怕的锁敌也保持原样。

目标事件、所属生物线程的目标／Brain 清理、伤害事件共同生效。跨区域只交换短时位置快照，不从受击线程读取远端生物的坐标或 Brain。

### 音乐

原曲约 **56.294 秒**循环，20 格可听范围，声音类别为 RECORDS。0.2.2 保留 0.2.1 的音量调整，将播放 volume 从 1.0 提高为 1.5，让距离衰减后的音乐更响；客户端近处音量仍受原版上限和玩家声音设置限制，并非振幅固定增加 50%。每个玩家最多同时听到 4 个玩偶，各用独立声音槽；停止一个来源不会把其他玩偶音轨一起停止。

原版声音协议不能任意 seek。本版内置 56 个无损 OGG 页边界尾段，中途靠近时按约 1 秒精度续播，再接入共同循环。**不承诺采样级同步或完全无缝**。离线时间不算入播放进度，切档不会重开当前音轨，停止／移除／卸载会清理自身声音。

## 成年傻子村民交易

普通右击成年、存活、清醒且未被其他买家占用的 NITWIT，使用原版村民交易窗口，保留真实职业和其他插件报价：

| 商品 | 基础价格 | 每日库存 |
| --- | --- | --- |
| 玩偶 | 8 绿宝石 | 16 次 |
| 遥控器 | 4 绿宝石 | 16 次 |

库存随村民共享，而非每玩家单独生成；由原版负责扣费、产物及 uses。两项报价 XP 为 0、价格倍率为 0、忽略折扣。没有酒交易。

按主世界 fullTime / 24000 的游戏日补货，睡觉跨日有效；回拨日期只重设基线，不立即补货。只重置本插件报价，不调用全体 restock。开窗跨日刷新报价和结果槽；玩家与村民暂未同属当前线程时延后同步，不跨区直接发包或抢占交易窗口。

## 命令与权限

| 命令 | 用途 |
| --- | --- |
| `/tongtou give [玩家]` | 发放通透模式，省略玩家时发给自己 |
| `/tongtou give <玩家> doll` | 发放玩偶 |
| `/tongtou give <玩家> remote` | 发放遥控器 |
| `/tongtou status` | 外观目录、手动会话、已加载玩偶、范围显示、资源状态 |
| `/tongtou stop` | 停止全部已加载玩偶和手动动画，来源变为停止，不会被下轮扫描自动开启 |
| `/tongtou reload` | 校验并重载动画／范围配置及目录；物品 ID 和手动会话上限需重启 |
| `/tongtou resources` | 重新生成模型并合入 CE 资源包 |

`tongtou.use`：手动通透，默认允许。`tongtou.party.use`：放置／开停玩偶及遥控，默认允许。`tongtou.admin`：管理命令，默认 OP。

默认上限：128 个已加载玩偶、8192 个跟踪 Mob、256 个范围模型、每玩家 4 个声音来源；范围控制与一次性通透会话分开计数。迁移后的 config.yml 不强行覆盖，新增项缺省时使用本版默认值。

## 自动资源升级与保存

- BetterModel：`plugins/BetterModel/models/tt_*.bbmodel`，共 823 个；其中 822 个原版模型列在 catalog，`tt_doll` 独立列在 feature-models。
- 本插件数据目录为 `plugins/FriendsWinePlugin/`：`catalog.json`、`coverage.json`、`feature-models.json`、`music.json`、持久化逻辑时钟 `party-clock.txt`。
- CE：`plugins/CraftEngine/resources/tongtou/` 的物品、家具、分类和 `resourcepack/assets/tongtou/` 素材。
- 946 个受管理文件逐个校验长度／SHA256，校验失败拒绝当成成功安装；路径禁止越界和符号链接。
- 未改文件自动升级，丢失文件自动补回。**管理员手改文件保留并警告**；若手改过 CE 分类／物品定义，需要自行合并新增两个条目和家具配置，插件不会覆盖。
- 合包指纹同时覆盖 BetterModel 输出和实际 CE／声音资源。只改音乐或 CE 配置也会触发更新；同一物理模型资源包仍去重登记。
- 玩偶自身 PDC 保存模式、稳定 ID 及播放／旋转进度，不写 CE 的 variant/data 字段。区块恢复与 CE 重载后核对实例并恢复控制；正常停用在所属线程清理。
- 旧数据迁移仅执行一次；保留旧目录作为备份。新目录中的 `.legacy-tongtou-migrated` 为迁移完成标记，`.installed-builtin.properties` 仍是资源升级账本。实体／物品PDC继续沿用 `tongtoumode` 命名空间，与插件显示名分离。
- 版本档案切换会把仍与旧账本hash一致的过期模型移入`compat-backups/<批次>/models/`，不直接删除；管理员改动保留，若与旧档案冲突则明确阻断切换。该机制不表示Minecraft世界可以安全降级。
- 不支持通过 PlugMan 热卸载本插件或前置，请正常停服重启。

## 原版外观覆盖与显示边界

仍为 **79 类实体、822 个外观条目**。未覆盖的 Mob 可以参与吸引和和平，但不会被替换成错误外形；详见释放后的 coverage.json。

原版替身是基础姿态，不完整复现行走、头部、攻击等全部原版动作；装备、项圈、特殊命名、程序化渲染存在适配限制。保留 0.1.4 的原 PNG／逐面 UV 和 0.1.5 首帧优化，不使用平均色三角形，不承诺任何网络和渲染设置下零闪烁。

普通石头、木板等方块没有动画入口。原模组的方块动画仅针对其玩偶，未增加普通方块动画或占位包。

## 构建与验证

仓库根目录，使用 JDK 25：

```powershell
& .\ports\folia-26.3\gradlew.bat -p .\ports\folia-26.3 clean build
python -I -X utf8 .\ports\folia-26.3\tools\test_build_models.py
python -I -X utf8 .\ports\folia-26.3\tools\test_textured_cubes.py
python -I -X utf8 .\ports\folia-26.3\tools\test_party_assets.py
```

clean build 直接使用 content/builtin-1.1.0.zip，不依赖 build 目录或服务器端 Python／FFmpeg。默认优先使用 Downloads 中指定版本的前置 JAR；可用 `-PbetterModelJar=...`、`-PcraftEngineJar=...` 改路径，旧后端可通过`-PlegacyBetterModelJar=...`指定1.15.2，缺失时使用Maven API。第三方前置不被打包。

开发者更新玩偶／音乐时先执行 tools/prepare_party_assets.py，再执行 tools/bundle_party_assets.py，最后执行 tools/prepare_compat_assets.py，并用`--input`指定源归档、`--output`指定全新目标归档；后者保留原版模型并重建完整清单。普通服务器无需做这一步。原版离线导出工具仍保留在 src/modelExporter/ 和 tools/build_models.py。

测试与未完成的实服验收见 VALIDATION.md。tools/smoke_server.py 使用全新、本机监听的测试目录，不触碰生产世界；执行外部服务端／前置代码前仍需操作者明确授权。本轮没有将离线测试冒充客户端画面或 Folia 实服并发验收。

## 素材与许可

动画计算复用仓库 JellyAnimation，玩偶／遥控器／音乐使用原工程素材并沿用其许可约束。原版模型与贴图来自操作者提供、校验的 Minecraft 26.3 客户端，分发与使用须遵守对应条款。前置插件本体不随插件分发。

资源生成器不会覆盖已有兼容归档。当前构建使用`content/builtin-1.1.0.zip`，保留`content/builtin-26.3.zip`作为先前开发输入，JAR只打包当前选定归档，不会重复包含两套音频。
